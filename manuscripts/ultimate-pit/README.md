# Technical report release boundary

`main.pdf` is the immutable PDF deposited for the existing v1.0 Zenodo record under concept DOI
[10.5281/zenodo.21519687](https://doi.org/10.5281/zenodo.21519687). It is retained for provenance and is not
silently overwritten.

The LaTeX source in `tex/main.tex` contains post-publication reference, licensing, and scheduling-scenario
clarifications. Those corrections are candidates for a future report version. Rebuilding, versioning, and
publishing that report requires an explicit release decision; ordinary software builds and deployments do not
alter the Zenodo record.
